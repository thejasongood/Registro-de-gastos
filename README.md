# Registro de Gastos

Programa hecho en C# para registrar y controlar gastos desde la consola.

## ¿Qué hace?

El programa permite:

* Agregar gastos
* Ver los gastos registrados
* Buscar gastos por categoría
* Ver el total gastado
* Guardar los datos en un archivo CSV
* Cargar los gastos guardados

## Datos que se registran

Cada gasto tiene:

* ID
* Descripción
* Monto
* Categoría

## Uso

Al iniciar aparece un menú con las opciones:

1. Agregar gasto
2. Listar gastos
3. Buscar por categoría
4. Salir y guardar

Los gastos se guardan en el archivo `gastos.csv`.

## Hecho con

* C#
* .NET
* Visual Studio

Proyecto realizado como práctica para aprender a trabajar con clases, listas, métodos y archivos en C#.
